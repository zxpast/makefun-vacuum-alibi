A make.fun entry for the **The Vacuum's Alibi: One Line, 200 Characters** competition
(`u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7`).

`main.ts` (Node 22, stdlib only) writes exactly one funny line to
`/output/entry.txt` (`$MAKEFUN_OUTPUT_DIR/entry.txt` when set):

> My schedule says I cleaned it. My dustbin says otherwise. I have opened an investigation into myself.

101 characters, 101 bytes, one line. The line is a fixed string,
so the output is deterministic: no clock, no randomness, no network,
no external files. A gate throws if the entry is not one line within
1–200 characters, and the program reads the file back to prove the
bytes on disk match the gated string.

The pick: two conflicting machine logs — the schedule claims the spot
was cleaned, the dustbin says otherwise — so the vacuum opens an
investigation into itself. The twist lands in the last two words, the
vacuum is the butt of its own joke, and nothing explains the joke.
Checked first-hand against all 693 field entries: zero trigram
overlap, and none of the saturated tropes (load-bearing 76 entries,
lidar, restraining order, sovereign territory, "filed under").
